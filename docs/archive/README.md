# docs/archive — closed documents

Nothing in this directory is live. A document lands here when the work it describes is finished
and the document has no remaining reader: an implementation plan that was executed, a review
verdict whose findings were all fixed, a PR draft whose PR was merged, an RCA whose defect is
closed, or a report that a newer measurement superseded.

Rules of the directory:

- **Never delete, only move.** Closed documents are the provenance of the fixes; the defect
  catalogue and the backlog point at them.
- **Every file carries a status box** under its first heading saying when it was archived, why,
  and where the work landed. The body below that box is left exactly as it was written — a
  superseded claim stays visible, it is not edited into agreement with today.
- **Open work never lives here.** If one question is still open in an otherwise finished document,
  the document stays in `docs/` and the open question is named in its status box.
- Live index: `BACKLOG.md` §5 "Where to read what".
