# M2 verdict: independent check of the own-beacon age-floor replay (D2)

Verifier V, 2026-11-01. I wrote my own script without reading or running M2's scripts:
`verify/lrf_checks/m2_verify/m2v.py` (stdlib, `python3 -I`). It reads the normalised logs only.

```
S=docs/log-reports/2026-11-01-24h/verify/lrf_checks/m2_verify/m2v.py; N=logs/20261101-24h-log/.logreport-work/norm
python3 -I $S counts $N      # (1) lost/aired per node and class
python3 -I $S gaps $N        # (2) gaps, own TX counts as occupancy;  M2V_RXONLY=1 python3 -I $S gaps $N  = decoded frames only
python3 -I $S airtime $N     # (3) TX_START -> OnTXDone per own TX
python3 -I $S replay $N      # (4)(6) simplified A1/A2/A3 replay, both nodes
python3 -I $S relays $N      # (5) relay matching
```

**Bottom line:** every M2 number I could test holds. Some hold exactly, the rest within about 10 %. Both contradictions
of the campaign doc are real. The model can say how many beacons the floor recovers, give or take about 20 %. It
cannot separate A1 from A2 on recovered count: the two differ by 4-12 %, which is less than the model error.

## Is the model fit to rank A1 / A2 / A3?

- **The order A1 >= A2 >= A3 follows from the code alone.** A1's hold is never longer than A2's, and A2 starts its
  floor before A3. In every model the order can only come out this way. It is no evidence that the model is good.
- **The size of the gain is solid.** Ideal and plite both bracket M2's values, and every model gives about 100-134
  recovered beacons in 25 h (OC+IA). That is roughly 70-90 % of the 142 TTL-lost.
- **A1 vs A2 lies inside the model error.** A1 recovers 5 (ideal) to 15 (plite) more than A2. That is 4-12 %, below
  the model uncertainty of about 20 %, and every model here is first-order: it ignores the extra beacons' own airtime
  and any hidden-node collisions in the rapid window. A1's cost is not in the count. It is the 100-275 ms window it
  shares with aged ACKs and relays (about 100-116 TX per 25 h).
- **A2 vs A3:** A3 recovers about 8 fewer in every model. The gap is small but has the same sign everywhere.

## Does the A2 recommendation stand?

Yes, on this evidence. A2 recovers about 110-130 of 142 lost own beacons at OC+IA, about 4-12 % fewer than A1, and
adds no TX to the rapid window. The doc's argument changes: "most gaps qualify" is wrong. Only about 26-30 % of
silences allow a stage-1 hold. A2 still works because a beacon sees many arm events at the head. The campaign doc
should replace "median gap 3.48 s" with 1.42 s (all frames) and "0.72 s per beacon" with 0.95 s WX / 0.44 s HEY.
