## Top corrections that change a verdict or a recommendation

1. **ACK-relay share (CORE Q6 line 1):** ACK relays alone are 41.3 % of cluster TX count and 20.2 % of airtime; 48.5 % / 25.9 % holds only for WJ's pings plus their ACK relays. The "biggest single channel load" verdict stands.
2. **Who sends the ping ACKs:** foreign gateways (GW-ACK format, byte 10 = 0x01, server bit), about 4.6 ACK ids per ping; none of the five, and HEAD never ACKs `{ping}` (`lora_functions.cpp:2169-2180`). The recommendation must name both levers: WJ's test pattern and the foreign gateways' firmware. "OE3XWJ causes" is right only as the trigger.
3. **Sole-provider artefact explanation:** the 12-h window is not the cause (case A is 100 % in the first hour after boot), and symmetric inference can supply the reverse edge. Point the design fix at the dependents rule and the alternative-provider test (`nbr_matrix.cpp:1777`, `:1816-1852`), not at `NBR_WINDOW_MIN`.
4. **Pair class "B heard A while queued":** for ACKs it means "heard any copy"; at least 336 of 1590 ACK pairs cannot be A's copy. The "36 % avoidable" is an upper bound; "hidden = almost all HL" is 78.5 %.
