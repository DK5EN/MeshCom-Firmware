## Top corrections that change a verdict or a recommendation

1. **OE3XIA silences (#1-#6): the verdict stays Handlungsbedarf, the diagnosis changes.** This is not
   desensitisation and not a logger drop. The SX1262 produces no RX IRQ at all (firmware util rx=0) while CAD
   still detects busy. 30/35 silences end right after a Standby+CAD cycle (base rate 20.6 %). The ~4.8-s
   `Radio.Rx()` watchdog re-issue does not recover it. Recommendation to test: Standby before the watchdog
   `startRadioReceive()` (`nrf52_main.cpp:1631`), plus a "no RX for N min -> Standby+Rx" guard.
   Hypothesis, depends on build.
2. **RX_ERROR shares (#18) are inflated by excluding ACK receptions.** The correct values are 7-32 % on OE3.
   The CRC verdicts for XIA/XIR/XOC/XWJ go from Beobachten to OK; DB0AIS (65.8 %) stays Beobachten.
3. **The OE3XIR interferer (#11) should not be called "not LoRa".** An RX_ERROR needs a detected preamble.
   Call it "strong local source, type unknown" and check the site (co-located LoRa equipment) first.
4. **"Build stamp 20260929" (#21) is FLASH_VERSION (release stamp).** It is not a build date, so it says
   little about the exact build.
5. Silence and longest-gap numbers on the other nodes (#8) are inflated by the same OnRxDone/ACK artefact
   (XHL 133 -> 68 s, XOC 133 -> 88 s). No verdict changes.
