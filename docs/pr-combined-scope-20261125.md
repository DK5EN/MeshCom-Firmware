# PR scope: combined upstream PR (AU + small fixes + gateway + RM + hmac_connect.py)

Base `upstream/dev` `68286e07` (= merge-base with `fork-dev`). Head `fork-dev` `732238bd`. Read-only analysis, no build.

Method: `git diff -U0 -w upstream/dev fork-dev` per file, every added line blamed with `git blame -w` on `fork-dev`,
hunks grouped by the blamed commit. Line numbers are **fork-dev** lines (`git show fork-dev:<file>`). "Comment-only"
hunks are upstream's copies of PR #1316/#1281 code with fork doc refs stripped: they always stay out (keep upstream's
text).

Key findings first:

- The older AU work (AU-01..AU-27, `7fa84e2c` .. `a43dd28e`) is already upstream (#1281, #1316). Their only surviving
  diff lines in `fw_update_net.cpp` are `#if INSTRUMENT_ENABLED` blocks (STAGELAN, heapgate, heap lines). AU content
  of this PR = `878ebef4`, `469bb942`, `f6c6acd7`, `5488f0bc`, `03a30cac` (AU-29 part only), `616850e2`, `493637e6`
  (schedule part), `d400b949`, `b7e99ffc`, `6afba162` (AU-22 part).
- **AU-28 has no firmware part.** `03a30cac` fixes FORMAL-01's own `tools/arduino_esp32_patch.py` (AE-01v2). Without
  FORMAL-01 there is no AE-01 and no AU-28 bug: AU-28 stays out with FORMAL-01.
- **The 32 KB AU buffer depends on the FORMAL-01 TLS allocation cap** (`fw_tls_alloc_cap.h`, `9696a3ba`) at compile
  time and in its logic (section C1). Decision needed (E1).
- `mc_tls` compiles without FORMAL-01 once the 138 `9696a3ba` lines (date check, TLS 1.2 floor, DNS via tcpip
  thread) are removed; nothing later builds on them (C2).
- The vendored mbedTLS copy is gone on `fork-dev` (`5488f0bc`); no file under `src/esp32/idf_override/mbedtls/`, no
  reference left.
- `#1308` register code calls `extSendDatagram()`, which comes from the `5d56dcba` refactor, and sits inside
  `EXT_NO_SOCKET` guards that come from `82627dcf` (`HAS_NRF_ETH`, not upstream). Both need a decision (B, C3).
- `platformio.ini`: no hunk is needed for topics 1-4 (the IN hunks there are fork native test envs only).

Legend for "Mode": **new** = whole file new; **whole** = whole-file diff goes in; **hunks** = only the listed hunks.
