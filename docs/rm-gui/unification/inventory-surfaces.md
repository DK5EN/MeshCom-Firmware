# Inventory: `--` command parser entry surfaces and external dependents

Repo: `/Users/martinwerner/WebDev/MeshCom-Firmware-DEV-Main` (branch fork-dev, read-only audit).
Paths below are repo-relative. Parser: `commandAction(char*, int iphone, bool rxFromPhone)` at
`src/command_functions.cpp:598` splits a line on embedded `--` and calls
`commandAction(char*, bool ble)` at `src/command_functions.cpp:743`, a ~7300-line ladder of
`commandCheck()` (exact-token, `command_functions.cpp:237`) and `ToggleRow` table rungs
(`src/command_toggles.h`). `commandAction` itself rejects anything not starting with `--`
(`command_functions.cpp:~752`, reply `--wrong command`). That is the ONLY syntactic gate in the
parser. There is no per-surface allowlist. The `ble` flag only changes replies/echo
(`command_functions.cpp:781, 737, 843`). The only command-set restrictions are at the surface
edges (table 1, column 4) and in the RM1 remote path (own positive allowlist).
