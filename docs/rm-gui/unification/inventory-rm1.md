### Conventions (section 2)

1. Verbs: single lowercase words, no separators, no capitals in the verb (RS:747-768, "cmd must be lower case"). Subforms are a space-separated argument, never a suffix.
2. On/off style: `on`/`off` everywhere (gps, track, display, gateway, mesh, setout, led+flash, chgled+auto); no 1/0 anywhere on the wire.
3. Read vs write: for the three RW verbs (name, atxt, pos) a bare verb is a read; with args it is a write. READ verbs (radio, sens, txq, mbox, maxhop, mh) take no args except mh, and any args on them give `err blocked`. ACTION and TOGGLE verbs are never reads: no args gives `err blocked`.
4. Reply: `RM1 <ctr> <result> <tag16>` (RS:710-745); result is `ok <body>` or `err <token>`. Body keys are `key=value`, space separated; absent value is `-`; list bodies (mh) are positional.
5. Lengths: args <= 39 (RM_MAX_ARGS, remote_cmd.h:48); result <= 108 (RM_MAX_RESULT, remote_cmd.h:47); formatter body <= 105 (rm_format.h:107); name <= 19 (RM_NAME_MAX, rm_commands.h:70); atxt <= 39; password <= 14 (rm_validate.h:18); call <= 9 (RM_CALL_MAX).
6. Charset: wire args printable ASCII 0x20-0x7E, single spaces, no leading/trailing space (RS:747-768). Forbidden anywhere in cmd or args: `;` `{` `%` `--` (RS:99-109). Reply sanitiser maps everything outside `[A-Za-z0-9 -./=+_@?(),*#]` to `?` (RS:850-862).
7. Counter: ctr is a uint32 1..0xFFFFFFFF (tools/remote_cmd.py:48); ctr 0 is reserved for sync.
8. Rate and lockout: 10 s between accepted commands (RM_RATE_MS, remote_cmd.h:41); sync 60 s; 3 rejects in 90 s lock the sender (remote_cmd.h:44-45).
9. Case: cmd lower case; args lower case except name, atxt, pos and mh (tool _MIXED_CASE_SHAPES; firmware RS:182-199 allows capitals in those shapes only).

## 3. Set differences

Firmware allowlist (RM_COMMAND_LIST, 23): reboot status sendpos sendtrack sync gps track display led gateway mesh txpower setout chgled radio sens txq mbox maxhop name atxt pos mh.

- tools/remote_cmd.py ALLOWLIST (tools/remote_cmd.py:59-85): same 23 names, same shapes. No name missing or extra. Matches.
- tools/remote_cmd.py BLOCKED_CMDS (tools/remote_cmd.py:87-92) names NOT on the firmware allowlist and not in RM_COMMAND_LIST: cleanflash, ota-update, dfu, deepsleep, setcall, passwd, webpwd, btcode, setssid, setpwd, wifiset, updrepo, updchan, autoupdate, rm, remotemgmt, stor, rmstrictsecurity. Firmware has no explicit deny list: these fall to `err blocked` (rmCheck RS:663, allowed() RS:205). Tool refuses before sending.
- Web page (src/web_functions/web_rm_page.cpp) sends: status, sendpos, sendtrack, reboot, sync (tile and data-act sync, web_rm_page.cpp:222-224, 396), gps, track, display, mesh, gateway, led, led flash (rm_sw rows, 222-226, 341), setout (rm_pin select, 385), chgled (rmSendCmd('chgled',v), ~line 233), radio, sens, txq, mbox, maxhop, name, atxt, pos (rmDefs, 266-269), mh (rmMhSend, `cmd=mh`, ~line 306). All are in the firmware list.
- Firmware list commands NOT offered on the web page: txpower (no tile, no write control; only the label parser at line 180 and a reply parser). The page also has no `track`-specific `ledflash` difference (ledflash is a UI alias for `led flash`, line 226 and 385).
- Firmware list commands NOT in tools/remote_cmd.py: none.
- Validation mismatches tool vs firmware (tool accepts, firmware answers with an error):
  - name/atxt: tool only bans `{ } | :` (+ `;%--` globally) and length. Firmware rmTextAllowed additionally refuses everything outside its charset (e.g. `#`, `=`, `~`, `<`, `>`, `"`, umlauts), leading/trailing/double space, name `none`, atxt `none`, and `,` `/` in atxt. Result: `err text`.
  - txpower: tool accepts 0..999 syntactically; firmware refuses outside max(0,TX_POWER_MIN)..TX_POWER_MAX (default 0..22) with `err range`. Sender policy (RT:958-973) applies the learned target range or 0..22 before sending; the CLI does not.
  - pos: tool regex accepts alt up to 99999 and lat/lon up to 999; firmware refuses lat >90, lon >180, alt >40000 with `err range`.
  - mh: tool and firmware call and row shapes agree (3..9 chars, optional -SSID 1-2 digits; row 1-3 digits).
  - setout, gps/track/display/mesh/gateway/led/chgled values: agree.
- Web page checks lat/lon/alt ranges (web_rm_page.cpp:275-278) and name/atxt length only; no charset check there, so firmware `err text` is the only charset gate for web writes.
